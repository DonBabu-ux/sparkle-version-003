# Sparkle Direct Messaging & Group Chat

Category: Messaging & Chat

## Sparkle Messaging Capabilities
Sparkle provides real-time chat for friends, study groups, and Marketplace buyer-seller conversations:
- **Direct Chat**: Message any verified Sparkle user directly from their profile or a Marketplace listing.
- **Group Chat**: Create campus group chats for study circles, hostel rooms, or club announcements.
- **Rich Media**: Send photos, voice notes, stickers, Giphy GIFs, and link previews.
- **Reply & Actions**: Long-press any message to reply, copy, delete, or react.
- **Marketplace Seller Chat**: Dedicated chat interface connected directly to listing IDs for safe price negotiation and meetup scheduling.
